Quick Reference

jsDelivr CDN Formats:

NPM Packages: cdn.jsdelivr.net/npm/package@version/file
GitHub Repos: cdn.jsdelivr.net/gh/user/repo@version/file
WordPress Plugins: cdn.jsdelivr.net/wp/plugins/slug@version/file
General Combine: cdn.jsdelivr.net/combine/url1,url2,url3
